## Shorts Repurposing Workflow
1. Record one take (30-60 sec)
2. Edit: captions + zoom cuts + music
3. Export 3 versions:
   - YouTube Shorts (9:16, clean)
   - Instagram Reels (9:16, add IG-native text overlay)
   - TikTok (9:16, add trending sound if relevant)
4. Post on all 3 platforms within same day
5. Cross-post text hook on X + Threads
