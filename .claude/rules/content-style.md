# Content Style Rules

## Video Content (YouTube)
- Hook FIRST — you have 3 seconds on shorts, 10 on long-form
- Story-driven: personal experience > abstract theory
- One core insight per video — don't try to cover everything
- Always end with a clear CTA
- Screen recordings for any AI/tech demonstrations

## Written Content (Landing Page, Social)
- Lead with the problem, not the solution
- Short paragraphs (1-3 sentences max)
- Use the ICP's language (from offer PDF)
- Bold the key phrases
- Every section earns the right to sell

## Content-to-Funnel Flow
```
Short-Form Video → hooks interest
     ↓
YouTube Long-Form → builds trust
     ↓
Landing Page (khalk.co) → presents offer
     ↓
Skool Community → converts & retains
```

## Script Length Guidelines
- YouTube Long-Form: 2,000-4,000 words (15-30 min)
- YouTube Shorts: 100-150 words (30-60 sec)
- Social Captions: 50-200 words
- Landing Page Sections: 50-150 words each
