# YouTube Strategy

## Channel Identity
- **Name:** Abdallah Khalk

## YouTube SEO Framework

### Title Optimization
- Include primary keyword in first 40 characters
- Use Darija + French/English search terms
- Formulas that work:
  - "Kifach [desired outcome] f [context]"
  - "[Topic A] vs [Topic B] — [judgment]"
  - "Ahssan [thing] f [year] ([tool/method])"

## Growth Tactics
1. **First 48 hours:** Share on all social, community, DMs to engaged followers
2. **Thumbnails:** A/B test with YouTube's built-in tool
3. **End screens:** Always point to community + next video
4. **Community tab:** Use for polls, teasers, engagement
5. **Collabs:** Guest on Moroccan YouTube/podcast channels
